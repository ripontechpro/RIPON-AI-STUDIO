# Ripon AI Studio

One Windows desktop application for photo editing, scanned-document cleanup, passport & ID sheets and print layout.

- Run from source: `python app.py`   (see **BUILD_WINDOWS.md** for the full CMD guide, EXE build and troubleshooting)
- Status, test results and limitations: **PROGRESS.md**
- Your photo on the Home screen: save it as `assets/ripon_photo.jpg` (a round placeholder is shown until then)
- AI models are optional and local; see Settings > AI models inside the app
