RIPON AI STUDIO  -  read me first
=================================

START
  Double-click  RiponAIStudio.exe   (keep the whole folder together; do not move the exe out of it).

WINDOWS SAYS "Windows protected your PC" OR AN ANTIVIRUS COMPLAINS?
  This program is new and not yet known to Windows, so Windows is careful with it. That is a reputation warning, not a virus finding.
  Check that the file is the real one: open a Command Prompt in the download folder and run
        certutil -hashfile RiponAIStudio-4.0.0-win64.zip SHA256
  The long code must match the one published next to the download (SHA256.txt).
  If it matches: click "More info", then "Run anyway".   If it does NOT match, delete the file and download again.

AI MODELS (optional, big files)
  The photo, document, passport and layout tools work without any AI model.
  Background removal, object removal, face restore and upscaling need model files.
  If a friend gave you a model pack (a .zip made by the app):
      Settings  >  Model backup & restore  >  Restore models...  >  choose that zip.
  Only restore packs from people you trust.
  Otherwise open  AI Studio > Download models  (downloads once, with your confirmation).

YOUR FILES
  Nothing is uploaded anywhere. Unsaved work is autosaved every minute and offered back if the program closes unexpectedly.
